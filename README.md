# ПЛИС на практике: Sipeed Tang Nano 20K

Учебное пособие для начинающих: от понятия сигнала до собственных схем в ПЛИС.
Предварительных знаний по электронике не требуется.

📄 **[Открыть PDF](./Tang_Nano_20K.pdf)**

## Содержание

**Часть I. Основы цифровой схемотехники** (общая база для всех курсов)

1. Сигналы: аналоговые и цифровые, логические уровни, двоичная система, временные диаграммы, тактовый сигнал
2. Логические элементы и булева алгебра: обозначения ГОСТ и ANSI, законы де Моргана, универсальные элементы
3. Комбинационные схемы: синтез по таблице истинности, карты Карно, задержки, «иголки»
4. Дешифраторы и шифраторы: 2→4, семисегментный индикатор, приоритетный шифратор, код Грея
5. Мультиплексоры и демультиплексоры: дерево мультиплексоров, мультиплексор как LUT, временное разделение каналов
6. Арифметические узлы: сумматоры, дополнительный код, вычитатель, компараторы, АЛУ
7. Триггеры: RS, D-защёлка, D-триггер, T и JK, setup/hold, метастабильность
8. Регистры и счётчики: сдвиговый регистр, LFSR, асинхронный и синхронный счётчики, делитель частоты
9. Синхронные схемы, конечные автоматы и память: f_max, конвейер, автомат Мура, ПЗУ, ОЗУ

**Часть II. ПЛИС на практике: Tang Nano 20K**

10. Что такое ПЛИС
11. Что внутри ПЛИС: LUT, CFU, трассировка, BSRAM, DSP, PLL
12. Плата Tang Nano 20K
13. Маршрут проектирования: Gowin EDA и открытые инструменты
14. Основы Verilog
15. Семь проектов: логические элементы, мигалка, бегущий огонь, кнопка с антидребезгом, светофор, ШИМ, дешифратор/мультиплексор/демультиплексор
16. Симуляция в Icarus Verilog и GTKWave
17. Встроенная SDRAM на 64 Мбит
18. Задания для самостоятельной работы

Приложение: шпаргалка.

## Структура

```
tex/        исходники XeLaTeX (main.tex, chapters/, styles/)
code/       примеры: в каждой папке .v (схема) и .cst (выводы с комментариями); common/tang_nano_20k.cst — сводная распиновка; Makefile
build.sh    сборка PDF в Linux/macOS
build.bat   сборка PDF в Windows
```

## Сборка PDF

Понадобятся XeLaTeX (TeX Live или MiKTeX) и Python-пакет Pygments (для `minted`):

```bash
./build.sh          # результат: Tang_Nano_20K.pdf
```

## Сборка примеров открытыми инструментами

```bash
cd code
make PROJECT=02_blink TOP=blink load     # синтез, трассировка и загрузка в SRAM
make PROJECT=02_blink TOP=blink flash    # запись во Flash
```

Симуляция:

```bash
cd code/01_gates && iverilog -o tb tb_gates.v gates.v && vvp tb
```
