# Tang Nano 20K: аппаратная проверка 2 октября 2026

Плата обнаружена как GW2AR-18C, ID `0x0000081B`. Встроенный USB-отладчик: VID/PID `0403:6010`, serial `2025030317`, интерфейс A, location 529. Использован уже установленный Gowin Programmer V1.9.11.03 Education на клиентском Windows-компьютере.

**Загрузка новой схемы в SRAM заработала.** После переподключения USB загружен свежий `clocked-pattern`, собранный Yosys → nextpnr → Apicula средствами Yosis. Пользователь подтвердил: чередуются две группы по три LED. В FPGA сейчас UserCode `35B1`; прежний бегущий огонь во flash сохранён. [Исходники, CST и повторение проверки](clocked-pattern/README.md).

Готовый официальный blink Sipeed и его пересборка установленным Gowin также физически мигают всеми шестью LED, что подтвердил пользователь. Независимый D2XX-пробник читает ID, UserCode и статус через текущий FTDI-драйвер. Драйвер и firmware BL616 не менялись.

Предыдущие комбинационные тесты кнопок и статичного рисунка остаются отдельной нерешённой проверкой: пользователь видел все шесть LED. Замена PULL NONE на UP не исправила статичный тест. Причина пока не установлена; успешный динамический тест не доказывает работу этих проектов.

Перед последней загрузкой после переподключения прочитан исходный UserCode `8896`. Затем `clocked-pattern` загружен только в SRAM; он остаётся текущей схемой. После отключения питания вернётся прежняя flash-конфигурация. Flash не стиралась и не перезаписывалась.

`Finished` и совпадение UserCode сами по себе не доказывают работу схемы; у успешных тестов дополнительно проверено физическое поведение. Подготовленный openFPGALoader v1.1.1 с libusb не открыл устройство под нынешним Windows-драйвером, поэтому текущая успешная загрузка выполнена установленным Gowin Programmer на клиентском компьютере.

## Сохранённые проекты

- [button-led-check](button-led-check/README.md): исходники, CST, testbench, скрипт настоящей сборки и `receipt.json`.
- [clocked-pattern](clocked-pattern/README.md): работающий аппаратный тест, Verilog/CST, независимый testbench, скрипт сборки, импортируемый `project.json`, карта и хэши битстримов.
- `official-blink/`: исходники и готовый битстрим Sipeed, точная пересборка новым Gowin и журналы успешных загрузок.
- `jtag-diagnostic/`: независимое чтение регистров через D2XX; отдельный SRAM-программатор проверен программными тестами, но на USB не запускался.
- `io-pattern/top.v` и `board.cst`: рисунок без входов/такта; три Tcl-сборки для сравнения режимов программатора.
- В этих каталогах сохранены журналы программирования; `.fs`, VCD, JSON размещения и `impl/` остаются локальными артефактами и исключены из Git.
- `button-led-check/programmer-header.py`: диагностическая добавка метаданных с проверкой CRC и неизменности исходных строк. Это не готовый серверный транспорт прошивки.

## Linux-сервер

Сборка и симуляция выполняются на сервере. USB находится у ученика; программирование требует браузерного JTAG-транспорта либо локального помощника на его компьютере. Windows Gowin CLI использован только для этого аппаратного стенда. Архитектурные условия записаны в [плане](../docs/implementation-plan.md#linux-сервер-и-плата-на-компьютере-ученика).

Распиновка сверена с [Apicula](https://github.com/YosysHQ/apicula/blob/master/examples/tangnano20k.cst) и [Sipeed](https://wiki.sipeed.com/hardware/en/tang/tang-nano-20k/nano-20k.html). Режим JTAG1149 и ограничение SecurityBit описаны в установленных руководствах Gowin SUG502 и UG290.
