# Домашние задания по презентациям Verilog (ТСП, подраздел 3.4)

Презентации «Основы проектирования на ПЛИС» и Verilog 01–20 сгруппированы в 7 папок; к каждой группе есть тест
«ДЗ N» с заданиями CodeRunner. Внутри группы и от группы к группе самостоятельность растёт:

| Уровень | Что делает ученик |
| --- | --- |
| 1 | по образцу: допишите пропуск |
| 2 | исправьте или измените готовый код |
| 3 | по описанию: порты заданы, содержимое пишете вы |
| 4 | по задаче: интерфейс задан, устройство продумываете сами |
| 5 | комплексное: несколько идей из разных уроков (кнопка с антидребезгом, UART) |

В группе 4 ученик пишет **испытательный стенд** для чужого модуля с редкими ошибками и **файл .cst**.
Полная карта «задание → какие знания нужны → где они объяснены» в [`coverage.md`](coverage.md).

## Как убедились, что презентации дают нужные знания

`build.py` для каждого задания хранит список нужных знаний (урок и характерная фраза) и при сборке:

1. ищет эту фразу в тексте PDF указанного урока;
2. проверяет, что урок входит в пройденные к этой группе;
3. прогоняет эталонное решение (должно пройти все тесты) и «неправильные» решения (каждое должно провалить хотя бы
   один тест) в Icarus Verilog; заготовка не должна проходить сама.

Если проверка не проходит, сборка завершается ошибкой. Затем `create_homework.php test` повторяет прогон эталонов
через настоящий CodeRunner и песочницу на сервере (на момент сборки: 28 из 28).

## Как собрать и загрузить

```sh
# локально (нужны Icarus Verilog, pdftotext, папка ТСП с презентациями)
IVERILOG=…/iverilog VVP=…/vvp python build.py /путь/к/ТСП            # questions.xml, homework.json, coverage.md
# на сервере Moodle (от пользователя веб-сервера)
php -d max_input_vars=5000 create_homework.php /путь/к/Moodle questions.xml homework.json import
php -d max_input_vars=5000 create_homework.php /путь/к/Moodle questions.xml homework.json test
php -d max_input_vars=5000 create_homework.php /путь/к/Moodle questions.xml homework.json structure
```

`structure` создаёт в подразделе страницу «Как работать с заданиями», папки с презентациями групп и **скрытые** тесты
«ДЗ N» (каждый следующий открывается при 60 из 100 за предыдущий); одиночные презентации после копирования в папки
удаляются (в корзине Moodle). Для обновления отдельных вопросов: `build.py --only 4.1 --no-prototype --out fix.xml`,
затем `HW_REPLACE=1 … import`.

Прототип `verilog_tb` для обычных заданий уже есть в банке вопросов курса (создан скриптами CodeRunner);
`verilog_py` (для проверки текста `.cst`) создаётся этим XML.
