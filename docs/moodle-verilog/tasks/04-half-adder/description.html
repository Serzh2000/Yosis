Сложим два одноразрядных числа a и b. Результат может быть от 0 до 2, то есть 10 в двоичной записи: нужны два выхода.

  • sum: младший разряд суммы;
  • carry: перенос в старший разряд (1, когда 1 + 1).
abcarrysum
0000
0101
1001
1110

Подсказка. sum равен 1, когда входы разные. Это элемент «исключающее ИЛИ», знак ^. А carry равен 1, когда оба входа равны 1: это уже знакомое И.
