Мультиплексор — это переключатель: он пропускает на выход один из двух входов. Какой именно, говорит управляющий вход sel.

  • если sel = 0, то y равен a;
  • если sel = 1, то y равен b.

Как записать выбор. В Verilog есть «условие в одну строку»: условие ? если_да : если_нет. Например, assign y = sel ? b : a; означает «если sel равен 1, взять b, иначе a».
