# Программирование из браузера

Целевой сценарий по последнему указанию пользователя: штатная Tang Nano 20K подключается в UPDATE/BOOT, браузер устанавливает DirtyJTAG на BL616, затем загружает FPGA по JTAG. Ученик работает с веб-приложением; драйверы и локальный помощник не устанавливаются вручную. Linux-сервер строит проект и раздаёт битстрим и комплект прошивки, а браузер обращается к локальной плате.

Полный цикл ещё не подтверждён на оборудовании. В MCU firmware найдены ошибки обработки пакетов и настройки UART; перед массовой установкой требуется новая сборка с исправлениями. [Ревью установки](dirtyjtag-install-review.md).

## Реализовано

| Этап | Реализация | Подтверждение |
| --- | --- | --- |
| Штатный загрузчик | Web Serial, Bouffalo CDC, handshake и BootInfo | Настоящая плата: `349b:6160`, `0x06160001`, sign 0, encrypt 1 |
| Установка BL616 | Нативные команды flash ROM, копия в IndexedDB, установка и восстановление, SHA-256 | 14 программных тестов; аппаратная запись пока не подтверждена |
| Комплект DirtyJTAG | Загрузчик Sipeed и собственная сборка с MS OS 2.0/WinUSB | Настоящий GCC/SDK; хэши и дескрипторы проверены |
| JTAG | DirtyJTAG и FTDI/MPSSE через WebUSB | Независимые модели USB/TAP; реальная браузерная запись ещё не подтверждена |
| Проверка FPGA | ID `0x0000081B`, Status, UserCode, CRC битстрима | Программные проверки и прежний аппаратный результат через Gowin Programmer |
| UART | Web Serial, выбор порта, скорость и терминал | Интерфейс реализован; обмен с FPGA ещё не проверен |

Мастер находится во вкладке «Подключение», в разделе «Установить DirtyJTAG / восстановить отладчик». [Комплект, адреса, хэши, резервные копии и повторная сборка](../hardware/dirtyjtag/README.md).

## Порядок работы

1. Подключить плату с удерживаемой UPDATE за HDMI, затем отпустить кнопку.
2. Нажать «Подготовить установку» и выбрать Bouffalo CDC. Браузер читает flash целиком, проверяет SHA-256 и сохраняет исходную копию. На этом этапе стирания нет.
3. Проверить сведения и запустить установку. Вторичная прошивка по адресу `0x20000` записывается раньше тела загрузчика; сектор 0 с его заголовком записывается последним. Каждый сектор и итоговая flash проверяются.
4. Переподключить USB без UPDATE. Выбрать DirtyJTAG и прочитать ID FPGA.
5. Синтезировать проект и выполнить размещение во вкладке «Кристалл». Выбрать свежую сборку и загрузить её в SRAM.

Поддерживаются обычные несжатые, незашифрованные текстовые FS GW2A-18C с CRC. Изменения HDL/CST блокируют старую сборку. Загрузка повторно проверяет пакет и FPGA; успех требует Done без ошибок и точного UserCode. Он не заменяет проверку поведения на плате.

Во время JTAG или подготовки отладчика UART заблокирован. Навигация по вкладкам сохраняет операцию, закрытие страницы вызывает предупреждение. Неудачные команды записи не повторяются автоматически. После отключения питания FPGA возвращается к программе из своей flash.

## Восстановление и ограничения

В BOOT доступно восстановление самой ранней сохранённой копии конкретного BL616. Копия находится в профиле браузера; очистка данных сайта удалит её. Перед записью приложение перечитывает копию и сверяет плату и текущее содержимое flash. При несовпадении запись блокируется.

На проверенном Windows-компьютере штатный `FTDIBUS` блокирует `claimInterface(0)`. Новый пакет объявляет WinUSB для JTAG и отдельный CDC UART; автоматическое назначение драйверов ещё нужно подтвердить аппаратно. Работа на любой ревизии платы пока не подтверждена. [Журнал испытаний](../hardware/browser-programming/README.md).

Флаг `encrypt=1` в BootInfo относится к IF-образам и не доказывает запрет нативных команд flash ROM. Новый установщик использует официальный путь `load_function=2`; RAM-мост не требуется. eFuse, произвольная память и полный chip erase не используются.

Браузер должен поддерживать Web Serial и WebUSB, страница — HTTPS или localhost. USB находится на клиентском компьютере, сервер доступа к нему не получает. WASM openFPGALoader тоже использует WebUSB `claimInterface`; смена JS на WASM сама по себе не устраняет штатный FTDIBUS. [Первичные источники](browser-programming-research.md).

## Ещё требуется аппаратная проверка

- Чтение полной flash нативным ROM и сохранение копии на текущей плате.
- Установка, переподключение, Windows WinUSB/usbser и восстановление исходного отладчика.
- ID FPGA, SRAM-загрузка контрольного битстрима и наблюдаемый рисунок LED через DirtyJTAG.
- UART и другие клиентские ОС/ревизии Tang Nano 20K.
