# Мобильная версия Logra

Один брейкпоинт — `max-width: 768px` (`MOBILE_QUERY` в `src/hooks/useIsMobile.ts`, те же числа в `src/mobile.css`).
Все мобильные правила лежат внутри этого `@media`, десктоп (1280×800) не меняется. Разметка отличается
только там, где одним CSS не обойтись: шапка, нижняя панель, шторки конструктора (хук `useIsMobile`).

## Что сделано

- **Нижняя панель вкладок** вместо левого меню: Код, Конструктор (или Выводы, если схемы нет), Диаграммы, Лаборатория и «Ещё» —
  шторка с остальными вкладками и «Файлы проекта» (`StudioNavigation`).
- **Шапка**: значок, имя проекта, кнопка «Синтезировать» только значком; «Создать проект», синхронизация, язык, тема и справка — в меню «⋯».
  Учтены вырез и нижняя полоса (`env(safe-area-inset-*)`, `viewport-fit=cover`), `theme-color` для светлой и тёмной темы.
- **Конструктор**: библиотека и свойства — нижние шторки (48 % высоты), холст на весь экран, панель инструментов прокручивается
  вбок; библиотека закрывается после добавления элемента; свойства по выбору элемента сами не открываются.
  Щипок двумя пальцами — масштаб и сдвиг (`src/lib/pinch.ts`, также в `CanvasViewport`); невидимая зона касания вывода увеличена.
- **Журнал сборки** — полоса 44 px, раскрывается на 42 % высоты. Панель файлов — на весь экран.
- **Лаборатория** — панель инструментов в одну прокручиваемую строку, сцена сверху, библиотека и подсказки ниже.
- **Планировщик выводов** — одна прокручиваемая страница вместо сжатых панелей.
- **Учебник `/learn`**: карточка шага — шторка под сценой, верхняя полоса сжата.
- **Цели касания**: кнопки, поля, вкладки и `select` ≥ 44 px (кроме Monaco, терминов словаря и сцены лаборатории).
- Подписи не мельче 12 px, цвета только из существующих токенов (тёмная и светлая темы).
- Новые тексты — `src/i18n/en-mobile.ts`.

## Проверено

Playwright (chromium, касание, `isMobile`) на 390×844 и 768×1024: окно «Проекты» и мастер, Код, Конструктор, Выводы, RTL,
Диаграммы, Лаборатория, Gowin, Кристалл, Подключение, Обучение, `/learn`. Горизонтальной прокрутки страницы нет нигде,
мелких целей (<44 px) не осталось, кроме отмеченных ниже. Тест: `e2e/mobile.spec.ts`.
Скриншоты «до» (`before-*`) и «после» (`after-*`) — в этой папке, 390 px.

## Остаточные проблемы

- Щипок не подключён к карте кристалла, лаборатории, форме волн и RTL-схеме (у них свои жесты/кнопки масштаба, на 390 px
  они работают кнопками); в конструкторе и `CanvasViewport` щипок есть.
- В конструкторе нет долгого нажатия для контекстного меню и режима «касание вместо наведения» для подсказок выводов;
  провод — перетаскиванием от вывода к выводу либо тапом по двум выводам (как и раньше).
- Зона касания вывода — 36 пользовательских единиц холста (при масштабе <1,2 меньше 44 px; больше нельзя без перекрытия соседних выводов).
- «Загрузить в SRAM» (панель «Подключение») — 40 px.
- Monaco: шрифт и перенос строк прежние; при выезде виртуальной клавиатуры редактор сжимается браузером, отдельной логики нет.
- Широкие таблицы и диаграммы (временные диаграммы, RTL) на 390 px требуют прокрутки вбок; шторка «Ещё» не показывает числа ограничений.
- Не проверено на реальных iOS/Android, только эмуляция.
