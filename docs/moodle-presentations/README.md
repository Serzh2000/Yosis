# Расстановка презентаций по курсам Moodle

Папка `ТСП` (10 тем, презентации и конспекты) разложена по курсам на `cdod.sakoryagin.ru`.

| Папка | Куда |
| --- | --- |
| 03 Материаловедение | ТСП, блок 3, подраздел 3.1 (1–10) |
| 04 Аддитивные технологии | ТСП, блок 1: в подразделы FDM, SLA, SLS, металлы; уроки 1 и 8 на уровне блока |
| 05 Станки и резка с ЧПУ | ТСП, блок 2: в подразделы фрезеровки, токарной, лазерной, гидроабразивной резки; плазменная на уровне блока |
| 01 Цифровая схемотехника | ТСП, подраздел 3.3 (введение, триггеры, шифраторы, сумматоры, АЛУ) |
| 01 ПЛИС и 02 Verilog | ТСП, **новый подраздел 3.4 «Проектирование электроники»**: «Основы проектирования на ПЛИС» и Verilog 01–20 |
| 06 БПЛА | БАС: блоки сохранены, презентации вложены в подразделы; экзаменационные билеты в «Правовые основы» |
| 07 Python | Python для школьников, раздел 1: расширенные «Типы данных в Python» и «Арифметические операции в Python» |
| 09 Linux | СиСа, подраздел «Работа с Linux (Ubuntu)» |
| 08 Arduino и ESP32 | новый скрытый курс «Arduino и ESP32» |
| 10 Проекты и мероприятия | не загружены (отдельный курс не создавали) |

Старые версии файлов, дубли и пустые подразделы скрыты, но не удалены. Журналы (что создано и что скрыто,
для отката) лежат на сервере в `/root/vpl/presentations/changes-*.json`; бэкап базы до работ:
`/root/moodle-db-before-presentations-20261113.sql.gz`.

## Как это сделано

```sh
python3 gen_manifest.py /папка/ТСП manifest.json      # что куда
sudo -u fastuser php -d max_input_vars=5000 apply_manifest.php /путь/к/Moodle manifest.json /папка/с/файлами dry     # пробный прогон
sudo -u fastuser php -d max_input_vars=5000 apply_manifest.php /путь/к/Moodle manifest.json /папка/с/файлами apply [курс]
sudo -u fastuser php -d max_input_vars=5000 reorder.php /путь/к/Moodle changes-КУРС.json   # новые файлы в начало разделов
```

Старые версии определяются по имени (и расширению) только среди элементов, которые были в курсе до начала работы,
поэтому повторный запуск ничего не дублирует.
