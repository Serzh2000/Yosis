# Glossary and translation rules (Russian -> English)

Book title: **Digital Design: from Logic Gates to FPGAs**. Author line: Sergey A. Koryagin. Product name: **Logra** (never "Yosis"). **Yosys** is the synthesis tool and stays as is.

## Layout words
Глава -> Chapter; Часть -> Part; Раздел -> Section; Рис. -> Figure; Таблица -> Table; Приложение -> Appendix; Задача/Задание -> Problem/Task; Ответы -> Answers; «Сделай сам» -> "Do it yourself"; «Соберите сначала» -> "Build it first"; «Типичные ошибки» -> "Common mistakes"; «Что дальше» -> "What's next"; «Заглянем вперёд» -> "Looking ahead"; «Главная мысль» -> "Key idea"; Справка -> Reference; Внимание! -> Warning!; Вопросы и задачи -> Questions and problems.
Difficulty stars keep the same macro `\stars{n}`.

## Terms (use consistently)
вентиль, логический элемент = gate (logic gate); триггер = flip-flop; защёлка = latch; такт = clock (cycle); тактовый сигнал = clock signal; фронт (нарастающий/спадающий) = (rising/falling) edge; ПЛИС = FPGA; шина = bus; карта Карно = Karnaugh map; дешифратор = decoder; шифратор = encoder; приоритетный шифратор = priority encoder; мультиплексор = multiplexer (MUX); демультиплексор = demultiplexer (DMUX); сумматор = adder; полусумматор = half adder; полный сумматор = full adder; вычитатель = subtractor; компаратор = comparator; конечный автомат = finite-state machine (FSM); автомат Мура/Мили = Moore/Mealy machine; регистр = register; сдвиговый регистр = shift register; счётчик = counter; делитель частоты = frequency divider; вывод (корпуса/ПЛИС) = pin; кристалл = chip (die); таблица истинности = truth table; булева алгебра = Boolean algebra; закон де Моргана = De Morgan's law; минтерм = minterm; импликанта = implicant; безразличное состояние = don't-care; задержка = delay; иголка (гонки) = glitch; гонки = race (hazard); метастабильность = metastability; время установки/удержания = setup/hold time; синхронный/асинхронный = synchronous/asynchronous; сброс = reset; разрешение = enable; схема (чертёж) = circuit / schematic; конструктор (Logra) = Designer; дребезг контактов = contact bounce; подтяжка = pull-up/pull-down; три состояния (Z) = tri-state (high impedance); ШИМ = PWM; ЦАП/АЦП = DAC/ADC; ПЗУ/ОЗУ = ROM/RAM; очередь FIFO = FIFO queue; код Грея = Gray code; двоично-десятичный код = BCD; дополнительный код = two's complement; чётность = parity; код Хэмминга = Hamming code; синдром = syndrome; фиксированная запятая = fixed point; семисегментный индикатор = seven-segment display; временная диаграмма = timing diagram; битстрим = bitstream; синтез = synthesis; размещение и трассировка = place and route; тестбенч = testbench; LUT stays LUT (lookup table); тактовый домен = clock domain; плата = board; прошивка = programming (loading the bitstream); охранная панель = security panel; кодовый замок = code lock; «Охранная панель» project = "Security Panel" project.
Numbers: decimal comma -> decimal point (2,5 -> 2.5); non-breaking thin space before units stays (\,MHz). Units: МГц -> MHz, нс -> ns, кОм -> k\textOmega (siunitx where used), В -> V, мА -> mA.

## Logra UI (English interface names)
Tabs: Learn (Обучение), Code (Код), Designer (Конструктор), Pins (Выводы), RTL, Waveforms (Диаграммы), Lab (Лаборатория), Gowin, Chip (Кристалл), Connect (Подключение). Lesson and example titles: use the exact English titles shown in the English interface (look them up in `src/i18n/en-content.ts` and the English files of the app; if an English title does not exist, translate literally and keep the example `id` in `\code{}`). Buttons: use English labels from the app.

## Code and figures
- Keep `\label`, `\ref`, `\cite`, macro names unchanged. Keep LaTeX structure and math untouched; translate only the prose, captions, titles, node labels in TikZ, table headers.
- TikZ labels with Russian text must be translated and re-checked for overflow (English words are usually shorter/longer; fix node sizes so nothing overlaps).
- Code listings: Verilog comments in English. Listings come from `code/` (Russian comments); the English edition uses `code-en/` (copy with English comments); `\codepath` is overridden in `tex-en/main.tex` to `../code-en`.
- Screenshots: `\shot` resolves `img/en/<name>` first (graphicspath), so keep the file names.
- Typography: English quotes (``like this''), em dash `---` with spaces removed where English style needs (word---word), no non-breaking tildes before Russian-specific abbreviations.
- Style: clear, textbook English for readers aged ~13+ and undergraduates; short sentences; avoid idioms. Second person ("you") like the Russian "вы".
