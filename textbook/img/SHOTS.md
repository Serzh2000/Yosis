# Снимки Logra для учебника

Русские снимки: `textbook/img/NAME.png`; английские: `textbook/img/en/NAME.png` (то же имя).
Светлая тема, `deviceScaleFactor` 2 (обзор окна 1500x1000, ширина PNG 3000 px) и 3 (схемы и диаграммы, окно 1100 px, ширина PNG до 3300 px).

## Как переснять

Из корня репозитория, при запущенном `npm run dev`:

    LANG_UI=ru node textbook/tools/shoot.mjs tour      # app-* (обзор интерфейса)
    LANG_UI=ru node textbook/tools/shoot.mjs bridge    # br-*
    LANG_UI=ru node textbook/tools/shoot.mjs gates     # ex-gates-rtl
    LANG_UI=ru node textbook/tools/shoot3.mjs [имя]    # n-*  (hamming iopad vending fifo sar pwm uart cpu sync)
    LANG_UI=en ...                                     # то же для английского, пишет в img/en

Переменные: `LANG_UI=ru|en`, `OUT_DIR` (от textbook/), `SCALE`, `THEME=light|dark`, `APP_URL`.

Все PNG в светлой теме, без потерь. При вставке на 16 см: диаграммы около 500 dpi, RTL около 380 dpi, обзорные кадры 3000 px около 480 dpi (на всю ширину).
Новые файлы сверх 31: нет (app-rtl и app-gowin уже были, но в главах не вставлены; app-gowin на примере «бегущий огонь» при масштабе 9% нечитаем, для главы берите br-adder-lut).

## Расхождения со старым текстом глав и замечания для правки

1. Слово Yosis осталось в интерфейсе Logra: в нижней строке состояния («Yosys готов» / «Yosys ready» -- это название программы Yosys, оно верно) и в имени области симуляции `__yosis_testbench.dut` (на снимках диаграмм скрыто стилем). Логотип и заголовок: Logra.
2. Вкладки теперь сгруппированы: «Узнать» (Обучение/Learn), «Создать» (Код/Code, Выводы/Pins), «Проверить» (RTL, Диаграммы/Waveforms, Лаборатория/Lab), свёрнутая группа «Настоящая плата» / «Real board» (Gowin, Кристалл/Chip, Подключение/Connect). В главах не должно быть «вкладка слева» без группы.
3. Кнопка запуска: «Синтезировать (Ctrl+Enter)» / «Synthesize» в правом верхнем углу; кнопка «Создать проект» / «New project» там же, рядом переключатели языка (RU/EN), темы и справки.
4. app-chip: теперь nextpnr показывает 338,87 МГц при 27 МГц для «бегущего огня» (в 07a_clocks подпись говорит 384,47 МГц: исправить на 338,87 или переснять с другим числом). Также панель названа «Размещение и трассировка», кнопка «Разместить и собрать», карта «Карта размещения на кристалле».
5. app-lab: слева «Найти среди 85 деталей» (в 03a_logra сказано «список из 68 деталей»: исправить на 85; английский: 85 parts).
6. app-wizard: пять карточек: «С нуля», «Из логических элементов», «На основе примера» (275 проектов), «Импорт проекта», «Папка проекта Gowin». Верхние кнопки: Создание, Мои проекты, Текущий проект, Синхронизация.
7. app-pins: подвкладки «Планировщик выводов» и «Текст .cst», трёхшаговая подсказка «Выберите сигнал, Выберите контакт, Нажмите «Назначить»»; кнопка «Назначить LED по порядку · 6».
8. app-conn: вкладка «Подключение» с переключателями «Загрузить схему», «UART-терминал», «Отладчик»; шаги 1-3; кнопка «Загрузить в SRAM».
9. app-learn: курс «Твоя мастерская» / «Your workshop», 31 урок; режимы «С наставником» / «Свободные задания».
10. br-adder-lut: инспектор справа называется «Инспектор», блок «Таблица LUT на 3 входа», «Таблица конфигурации INIT 0xE8», сворачиваемая «Таблица истинности · 8 строк». В окне 1100 px меню слева сворачивается в иконки.
11. n-cpu-rtl: автоматическая раскладка схемы процессора (50 элементов, 171 связь) нечитаема как учебная картинка (много проводов, текст мелкий) и не показывает «регистры PC, IR, ACC» крупно; подпись «RTL-схема процессора: регистры PC, IR, ACC, память RAM, сумматор и мультиплексоры» обещает больше, чем видно. Лучше заменить на нарисованную блок-схему в TikZ или сказать в подписи, что это общий вид.
12. Диаграммы: сценарий «Перебрать входы» / «Sweep inputs»; цвет линий коричнево-золотой, не зелёный (если текст говорит про цвет линий).
13. Значения формата по умолчанию HEX; для шины показано «0x..» с префиксом.
14. На br-fsm-wave нижняя строка `a[2:0]` бледная (это внутренний сигнал автомата). При желании можно убрать повторной съёмкой с другим набором сигналов.
