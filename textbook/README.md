# Цифровая схемотехника: от логических элементов до ПЛИС

**Русский** · [English](./README.en.md)

Учебное пособие для начинающих в двух изданиях (русском и английском одинаковой структуры). Книга построена как
«проектируй → запусти → наблюдай»: каждый раздел теории заканчивается заданием «Сделай сам» в среде
[Logra](../README.md), а книга организована как цепочка глав-«спринтов» со сквозным проектом
«Охранная панель». Предварительных знаний по электронике не требуется.

Примеры из книги собираются теми же открытыми инструментами, что и в Logra: Yosys, nextpnr и Project Apicula;
исходники (`.v`, `.cst`) можно брать как стартовые проекты для вкладок «Код» и «Выводы».

## Содержание

Книга одна, сквозная, без деления на части: теория, Verilog и работа в Logra идут вместе. Порядок глав:

**Старт**

1. Что такое ПЛИС
2. Первый спринт в Logra: вкладки, цикл «проектируй → запусти → наблюдай»

**Спринты по темам** (теория + Verilog + Logra вместе)

3. Сигналы: бит, логические уровни, временные диаграммы, тактовый сигнал
4. Системы счисления и коды: HEX, BCD, ASCII, код Грея, чётность, код Хэмминга, фиксированная запятая
5. Логические элементы и булева алгебра
6. Основы Verilog: код описывает схему, `assign`, `always`, модули
7. Комбинационные схемы: синтез по таблице истинности, карты Карно, задержки, «иголки»
8. Минимизация логических функций (в том числе углублённые разделы: Квайн --- Мак-Класки)
9. Дешифраторы и шифраторы, семисегментный индикатор
10. Мультиплексоры и демультиплексоры
11. Арифметические узлы: сумматоры, знак и переполнение, компараторы, АЛУ
12. Триггеры
13. Регистры и счётчики
14. Синхронные схемы, автоматы и память
15. Проектирование автоматов и очереди FIFO (сквозной проект: автомат «Охранная панель»)

**Плата, маршрут проектирования, физика, аналог**

16. Что внутри ПЛИС: LUT, триггеры, трассировка
17. Плата Sipeed Tang Nano 20K
18. От текста до работающей схемы: маршрут проектирования
19. Электрические основы: КМОП, выходы, шины, подтяжки
20. Цифра и аналоговый мир: ЦАП, АЦП, ШИМ
21. Те же узлы на Verilog: мост от схем к коду, «Охранная панель» на Verilog

**Проекты и системы**

22. Практика: семь проектов
23. Симуляция и тестбенчи
24. Тактирование, временной анализ, тактовые домены
25. Последовательные интерфейсы: UART, SPI, I²C
26. Память SDRAM
27. Собираем процессор
28. Задания для самостоятельной работы

**Приложения:** шпаргалка; ответы к задачам (с ходом решения и уровнем); соответствие глав и уроков Logra.

## Как устроены «спринты» и «Сделай сам»

Глава-спринт: мостик «что умеем → какой вопрос остался»; врезка «Соберите сначала» (задание в Logra до теории);
теория (существующий текст, сшитый между главами); в **каждом разделе** --- врезка «Сделай сам» (задание,
ожидаемый результат, как проверить на вкладках Диаграммы/RTL/Gowin); «Типичные ошибки»; «Вопросы и задачи» трёх
уровней (★ повтори, ★★ измени/найди ошибку, ★★★ проект с критерием приёмки); «Что дальше». Названия уроков и
примеров Logra сверяются со `src/` скриптом `tools/gen_map.py` (он же порождает приложение-таблицу).
План и журнал работ: [PLAN.md](./PLAN.md), аудит исходной структуры: [AUDIT.md](./AUDIT.md).

## Структура

```
tex/        русское издание (main.tex, chapters/, styles/ --- общая преамбула для обоих изданий)
tex-en/     английское издание (main.tex, chapters/, GLOSSARY.md --- единая терминология)
code/       примеры с русскими комментариями (.v, .cst, Makefile)
code-en/    те же примеры с английскими комментариями (для английского издания)
img/        русские снимки Logra; img/en/ --- английские (одно имя файла), SHOTS.md --- как сделаны
tools/      shoot.mjs, shoot3.mjs, lib.mjs --- снимки интерфейса (Playwright);
            gen_tasks.py, tasks_ext.py --- ответы к задачам русского издания (приложение B);
            gen_map.py --- таблица «глава ↔ урок Logra ↔ пример»;
            audit_forward.py, audit_terms.py, audit_overlap.py, audit_figures.py, audit_figure_text.py --- проверки
build.sh, build.bat   сборка: аргумент ru (по умолчанию) или en
Digital_Design_ru.pdf, Digital_Design_en.pdf, Digital_Design.pdf (копия русского)
```

Задачи лежат в самих главах; приложение «Ответы» русского издания порождается `python tools/gen_tasks.py`
(после правки ответов), английское приложение (`tex-en/chapters/a2_answers.tex`) правится вручную.

## Сборка PDF

Нужны XeLaTeX (TeX Live 2024 или новее, либо MiKTeX) и Python с Pygments (для `minted`, сборка идёт с `-shell-escape`).

```bash
cd textbook
./build.sh ru       # или: build.bat ru    -> Digital_Design_ru.pdf и Digital_Design.pdf
./build.sh en       # или: build.bat en    -> Digital_Design_en.pdf
```

Промежуточные файлы в `build/ru`, `build/en` (в репозиторий не попадают). Если `minted` пишет, что не находит
`main.listing`, удалите соответствующую папку `build/<язык>` и соберите заново (устаревший кэш подсветки).
В PowerShell: `Set-Location textbook\tex; $env:TEXMF_OUTPUT_DIRECTORY='../build/ru'; & xelatex -shell-escape -interaction=nonstopmode '-output-directory=../build/ru' main.tex` дважды.

## Обновление снимков экрана

Запустите Logra (`npm run dev` в корне репозитория; http://127.0.0.1:5173) и из корня репозитория:

```bash
LANG_UI=ru node textbook/tools/shoot.mjs tour      # затем bridge, gates
LANG_UI=ru node textbook/tools/shoot3.mjs
LANG_UI=en node textbook/tools/shoot.mjs tour      # английские снимки попадают в textbook/img/en
LANG_UI=en node textbook/tools/shoot3.mjs
```

Переменные: `OUT_DIR`, `SCALE` (device scale factor), `THEME` (для печати светлая), `APP_URL`. Описание каждого кадра: `img/SHOTS.md`.

## Проверки

```bash
python tools/audit_forward.py    # в каждом \section есть «Сделай сам»; нет ссылок вперёд на более поздние главы (кроме \lookahead, buildbox, diybox, «Что дальше»); до главы 6 нет Verilog вне \lookahead; имена уроков существуют
python tools/audit_terms.py      # термины, слово «Yosis» (должно быть 0)
python tools/gen_map.py --check  # id и названия уроков/примеров в таблице существуют в src/
```

## Проверка и сборка примеров

Примеры проверяются в Icarus Verilog (`cd code/00_theory; iverilog -o tb tb_hamming74.v hamming74.v && vvp tb` и т.д.,
см. `code/Makefile`); сборка открытыми инструментами: `cd code; make PROJECT=02_blink TOP=blink load`.
