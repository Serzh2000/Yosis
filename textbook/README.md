# Цифровая схемотехника: от логических элементов до ПЛИС

Учебное пособие для начинающих. Часть I --- комбинационная и последовательная логика с задачами и ответами.
Часть II --- ПЛИС Sipeed Tang Nano 20K и среда Yosis, со снимками экрана. Предварительных знаний по электронике не требуется.

Книга входит в проект [Yosis · FPGA Studio](../README.md). Примеры из неё собираются теми же открытыми
инструментами, что и в Yosis: Yosys, nextpnr и Project Apicula, а исходники (`.v` и `.cst`) можно брать
как стартовые проекты для вкладок «Код» и «Выводы».

**[Открыть PDF](./Digital_Design.pdf)**

## Содержание

**Часть I. Комбинационная и последовательная логика** (в конце каждой главы задачи, ответы в приложении)

1. Сигналы: аналоговые и цифровые, логические уровни, двоичная система, временные диаграммы, тактовый сигнал
2. Системы счисления и коды: шестнадцатеричная система, BCD, ASCII, бит чётности, код Хэмминга, фиксированная и плавающая запятая
3. Логические элементы и булева алгебра: обозначения ГОСТ и ANSI, законы де Моргана, универсальные элементы
4. Комбинационные схемы: синтез по таблице истинности, карты Карно, задержки, «иголки»
5. Минимизация логических функций: карты Карно на 4 переменные, безразличные состояния, метод Квайна---Мак-Класки, многоуровневые схемы
6. Дешифраторы и шифраторы: 2→4, семисегментный индикатор, приоритетный шифратор, код Грея
7. Мультиплексоры и демультиплексоры: дерево мультиплексоров, мультиплексор как LUT, временное разделение каналов
8. Электрические основы: КМОП, пороги и помехоустойчивость, выходы с тремя состояниями, открытый сток, шины, подтяжки
9. Арифметические узлы: сумматоры, дополнительный код, вычитатель, компараторы, АЛУ
10. Триггеры: RS, D-защёлка, D-триггер, T и JK, setup/hold, метастабильность
11. Регистры и счётчики: сдвиговый регистр, LFSR, асинхронный и синхронный счётчики, делитель частоты
12. Синхронные схемы, конечные автоматы и память: f_max, конвейер, автомат Мура, ПЗУ, ОЗУ
13. Проектирование автоматов и очереди FIFO: граф и таблица переходов, автомат Мили, кодирование состояний, FIFO
14. Цифра и аналоговый мир: дискретизация, квантование, ЦАП, ШИМ, АЦП последовательного приближения

**Часть II. ПЛИС и среда Yosis: Tang Nano 20K**

15. Что такое ПЛИС
16. Что внутри ПЛИС: LUT, CFU, трассировка, BSRAM, DSP, PLL
17. Плата Tang Nano 20K
18. Среда Yosis: лаборатория в браузере (снимки всех вкладок, сценарии симуляции)
19. Маршрут проектирования: Gowin EDA и открытые инструменты
20. Основы Verilog
21. От теории к Verilog: сумматор, дешифратор, защёлка и триггер, счётчик, автомат --- в Yosis
22. Семь проектов: логические элементы, мигалка, бегущий огонь, кнопка с антидребезгом, светофор, ШИМ, дешифратор/мультиплексор/демультиплексор
23. Последовательные интерфейсы: UART (передатчик и приёмник), SPI, I²C
24. Симуляция в Icarus Verilog и GTKWave
25. Тактирование, временной анализ и тактовые домены: slack, отчёт nextpnr, clock enable, PLL, синхронизатор, дребезг
26. Встроенная SDRAM на 64 Мбит
27. Собираем процессор: тракт данных, система команд, программа Фибоначчи
28. Задания для самостоятельной работы

Приложения: шпаргалка; ответы к задачам.

## Структура

Все пути считаются от папки `textbook/` в корне репозитория.

```
tex/        исходники XeLaTeX (main.tex, chapters/, styles/)
code/       примеры: в каждой папке .v (схема) и .cst (выводы с комментариями);
            00_theory/ — узлы первой части на Verilog с проверками (главы 2, 8, 13, 14, 21);
            08_uart/, 09_cpu/, 10_clocks/ — примеры глав 23, 27 и 25;
            common/tang_nano_20k.cst — сводная распиновка; Makefile
img/        снимки экрана Yosis (получены скриптами tools/shoot.mjs и tools/shoot3.mjs)
tools/      shoot.mjs, shoot3.mjs — снимки интерфейса Yosis через Playwright;
            gen_tasks.py, tasks_ext.py — задачи и ответы к главам
build.sh    сборка PDF в Linux и macOS
build.bat   сборка PDF в Windows
Digital_Design.pdf   собранная книга (обновляется после сборки)
```

## Сборка PDF

Понадобятся XeLaTeX (TeX Live 2024 или новее, либо MiKTeX) и Python с пакетом Pygments: он нужен
пакету `minted` для подсветки листингов, поэтому сборка идёт с ключом `-shell-escape`.

```bash
cd textbook
./build.sh          # Linux и macOS
build.bat           # Windows
```

Результат: `Digital_Design.pdf` рядом со скриптом. Промежуточные файлы остаются в `build/`, в репозиторий
они не попадают. Если `minted` ругается, что не находит файл `main.listing`, удалите папку `build/` и
соберите заново: проблема в устаревшем кэше подсветки.

## Проверка примеров

Примеры проверяются в Icarus Verilog (в Yosis он лежит в `.tools/iverilog`):

```bash
cd textbook/code/00_theory
iverilog -o tb tb_hamming74.v hamming74.v && vvp tb     # то же для vending, fifo8, sar_adc
cd ../08_uart  && iverilog -o tb tb_uart.v uart.v && vvp tb
cd ../09_cpu   && iverilog -o tb tb_tiny_cpu.v tiny_cpu.v && vvp tb
cd ../10_clocks && iverilog -o tb tb_debounce.v sync2ff.v && vvp tb
```

Каждая проверка печатает `OK`, если схема ведёт себя так, как описано в книге.

## Сборка примеров открытыми инструментами

Нужны Yosys, nextpnr-himbaechel, Project Apicula (`gowin_pack`) и `openFPGALoader`.

```bash
cd textbook/code
make PROJECT=02_blink TOP=blink load     # синтез, трассировка и загрузка в SRAM
make PROJECT=02_blink TOP=blink flash    # запись во Flash
```

Симуляция:

```bash
cd textbook/code/01_gates && iverilog -o tb tb_gates.v gates.v && vvp tb
```

## Обновление снимков экрана

Снимки в `img/` делает Playwright с Microsoft Edge. Запустите Yosis (`npm run dev` в корне репозитория) и выполните:

```bash
cd textbook
node tools/shoot.mjs          # обзор среды и главы 18, 21, 22; можно указать tour, bridge или gates
node tools/shoot3.mjs         # главы 2, 8, 13, 14, 23, 25, 27; можно указать имя снимка (vending, uart, cpu, ...)
```

Адрес Yosis задан в `tools/lib.mjs` (по умолчанию `http://127.0.0.1:5173/`).
